# Student Management System

A simple **Student Management System** developed using Python that helps manage student records efficiently. The system allows users to add, view, update, search, and delete student information.

## 📌 Project Overview

The Student Management System is a console-based application designed to perform basic CRUD operations on student data.

CRUD stands for:

- **C** - Create (Add new student records)
- **R** - Read (View student details)
- **U** - Update (Modify existing student information)
- **D** - Delete (Remove student records)

This project demonstrates the use of **Python OOP concepts**, data structures, and file handling.

---

## 🚀 Features

- Add new student details
- Display all student records
- Search student by ID
- Update student information
- Delete student records
- Store and manage student data
- User-friendly menu-driven interface
